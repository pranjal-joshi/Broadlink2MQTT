Your Broadlink blaster, as real Home Assistant

An add-on that bridges Broadlink RM devices to MQTT and publishes them as native infrared emitter and receiver entities — the ones the official integration cannot give you. No custom components, no YAML templates, no base64 wrangling.

Why this exists

Home Assistant 2026.4 added infrared entities. 2026.8 added the MQTT emitter and receiver schemas. The official Broadlink integration still cannot use either — and there is a good reason.

A Broadlink RM cannot listen passively. To receive anything it must be put into learning mode and polled, and that session dies the moment anything else touches the IR front end. core#177767 proposed doing exactly that inside the integration, and was closed:

The Infrared receiver entity is meant to be used by devices that can receive constantly […] I don't think it should be implemented for Broadlink until Broadlink provides a firmware that allows for constant receiving.

The objection is about where the state machine lives, not whether it works. Outside of core — where a capture window is driven by a switch you control — the same approach is perfectly sound. This add-on is that state machine, moved into its own process and wired to MQTT discovery.

What you get

Every blaster arrives as one Home Assistant device with a full set of entities.

📡 Infrared Emitter

A real infrared entity. Works with infrared.send_command and with device integrations like LG Infrared.

🎯 Infrared Receiver

Captured signals reported as raw microsecond timings, ready for automations and triggers.

🎓 Learning Mode Switch

Opens a bounded capture window that extends as codes arrive and closes itself when you're done.

📋 Last Captured Code

A sensor holding the most recent capture, with the base64 packet and raw timings as attributes.

🌡️ Temperature & Humidity

Published automatically for RM pro, RM4 mini and RM4 pro, so you can drop the official integration entirely.

🔌 Zero-config MQTT

Leave the broker blank and the add-on asks the Supervisor for the one you already run. No credentials to copy.

Get started in 3 steps

  1. Add the repository

    Settings → Add-ons → Add-on Store → ⋮ → Repositories, then paste the repo URL. Full detail on the install page.

  2. Install and start

    The defaults work if you run the Mosquitto broker add-on. Your blaster is found by UDP broadcast.

  3. Capture a code

    Turn on Learning mode, press a button on your remote, and watch the receiver fire. See usage.
